# 홈 강화안 (HOME v2) — 적용 명세

레퍼런스: `머니냥 홈 강화안.dc.html` (6a 근무 중 / 6b 출근 전 / 6c PC)
전제: 계산 로직 무접촉. 기존 렌더 함수 반환값을 새 마크업에 바인딩만 한다.

## 0. 목표

기존 홈은 요소가 동등한 무게로 나열돼 있었다. 새 홈은 **지금 시각에 필요한 하나**만
크게 보여주고, 나머지는 스와이프 뒤로 보낸다.

## 1. 제거할 것 (모바일 홈)

- **빠른 실행 4버튼** — 기능은 각 화면에 이미 있다. 홈에서 제거.
- **내 자산 카드** — 수입/생존 화면 소관. 홈에서 제거.
- 기타 대시보드 위젯 중 "오늘"과 무관한 것 전부.

제거가 아니라 **이동**이므로, 해당 기능으로 가는 경로가 탭·화면 안에 존재하는지 먼저 확인하고
없으면 그 화면에 먼저 추가한 뒤 홈에서 뺀다. 기능 삭제가 아니다.

## 2. 히어로 카드 — 상태에 따라 완전히 교체

홈 최상단에 카드 하나. 현재 근무 상태에 따라 **두 가지 형태 중 하나만** 렌더한다.
버튼은 항상 하나다.

### 2-A. 근무 중 (출근 기록 있고 퇴근 기록 없음)

```
배경 #2563EB (다크 #1D4ED8), radius 22, padding 20
├ 상태 줄:  ● 초록 8px(#4ADE80) + "근무 중 · {사업장명}"   13.5px/700, opacity .85
├ 경과 시간: "5시간 24분"   44px/900, letter-spacing -.03em      ← 화면 최대 요소
├ 보조 줄:  "09:30 출근 · 지금까지 62,100원"  15px, 금액만 #FDE68A/bold
├ 진행 게이지: 높이 7px, radius 999
│   트랙 rgba(248,250,252,.25) / 채움 #F59E0B, width = 경과/예정 * 100%
│   하단 라벨 12.5px: 좌 "8시간 예정" / 우 "18:00 퇴근 예정"
└ CTA: 높이 52px, radius 16, 배경 #F8FAFC, 글자 #1E3A8A 17px/900
    아이콘(로그아웃 화살표) + "지금 퇴근 기록"
```

- 경과 시간은 1분 단위로 갱신(기존 타이머 있으면 재사용).
- 게이지 채움은 예정 근무시간 초과 시 100%로 clamp하고, 초과분은 라벨에
  "+32분 초과"로 표기(색은 #FDE68A).

### 2-B. 출근 전 / 퇴근 후

```
배경 #FFFFFF, 보더 1px #E2E8F0, radius 22, padding 20
├ 라벨: "다음 근무까지"  13.5px/700 #64748B      (오늘 근무 끝났으면 "오늘 근무 완료")
├ 카운트다운: "1시간 12분"  44px/900 #1E293B
├ 보조 줄: "카페 어반빈 · 09:30 시작 · 예상 86,200원"  15px, 금액 #B45309/bold
├ 날씨 힌트 바 (날씨 데이터 있을 때만): 배경 #F1F5F9, radius 14, padding 11/13
│   날씨 SVG 19px + "출근길에 비가 와요. 우산 챙기세요"  13.5px #475569
└ CTA: 높이 54px, radius 16, 배경 #2563EB, 글자 #F8FAFC 18px/900
    shadow 0 4px 14px rgba(30,41,59,.25)
    아이콘(로그인 화살표) + "출근 도장 찍기"
```

- 오늘 근무가 모두 끝난 경우: 카운트다운 자리에 "오늘 +142,300원"(총 수입),
  CTA는 감추고 대신 "근태 기록 보기" 텍스트 링크.
- 등록된 근무가 아예 없는 경우: 카운트다운 자리에 "근무 일정이 없어요",
  CTA는 "근무 등록하기".

## 3. "오늘 남은 일" 목록

히어로 아래. 섹션 라벨 13.5px/900 #475569, 문구는 **"오늘 남은 일"로 통일**
(근무 중 상태에서도 같은 라벨).

각 행: 배경 #FFF, 보더 1px #E2E8F0, radius 16, padding 14/16, gap 12
- 좌측 노드: 11px 원, 보더 2.5px #CBD5E1, 배경 #F8FAFC (완료 시 #22C55E 채움)
- 본문: 제목 15.5px/700 + 부제 13px #64748B
- 우측 시그넛(>) 18px #94A3B8 — 탭 가능한 행에만

행 종류:
1. 남은 근무 — "편의점 야간 / 19:00 시작 · 예상 24,100원" → 탭 시 근태 화면
2. 미기록 유도 — 오늘 지출 기록이 0건일 때만 "오늘 지출 기록 안 했어요 /
   마이크로 '점심 9천원' 이라고 말해도 돼요" (시그넛 없음, 탭 시 마이크 열기)

남은 일이 하나도 없으면 섹션 전체를 렌더하지 않는다(빈 상태 문구 만들지 말 것).

## 4. 월 요약 바 (최하단)

배경 #1E293B(다크 #2E3A4E), radius 16, padding 15/17, 흰 글자
좌 "이번 달 예상 수입" 14px opacity .8 / 우 금액 16px/900 + 시그넛
탭 시 수입 화면(idx 3)으로 이동.

## 5. 경고 카드 (조건부)

생존 경고가 있을 때만 히어로와 목록 사이 또는 최하단에 1개.
배경 #FFEDD5, radius 16, 경고 삼각 SVG + 텍스트 14.5px #9A3412.
2개 이상이면 가장 심각한 것 하나만 홈에 노출하고 나머지는 정보 화면.

## 6. PC (6c)

**히어로를 키우지 않는다. 위계를 넓힌다.**

```
grid-template-columns: 1.35fr 1fr; gap: 20px; padding: 24px 28px
좌: 히어로 카드 하나 (padding 26/28, 숫자 58px, CTA 56px)
우: 세로 스택 gap 14
    ├ "오늘 남은 일" 카드 (radius 20, 행 사이 구분선 #EEF2F7)
    ├ 날씨 카드 (그라디언트 토큰, radius 20, 기온 30px)
    └ 경고 카드 (조건부)
```

- 사이드바 하단에 월 예상 수입 고정: `rgba(248,250,252,.1)` 박스, radius 14,
  라벨 12.5px #A9BCE8 + 금액 17px/900 #F8FAFC. 어느 화면에서도 보인다.
- 상단 바 우측: 오늘 수입 칩(#FEF3C7/#B45309) + 마이크 44px + "냥이 비서" pill.
- 우측 열은 스와이프 뒤에 있던 정보를 **미리 보여주는 용도**로만 쓴다.
  홈에만 있는 새 기능을 여기 넣지 말 것.

## 7. 숫자 일관성 (검수에서 걸린 항목)

- 헤더 칩 "오늘 +N원" 은 **누적 실적**이다. 근무 중이면 히어로의 "지금까지" 금액과
  같은 값이어야 한다. 하루 예상액을 넣지 말 것.
- 출근 전에는 헤더 칩 "오늘 0원"(#F1F5F9/#64748B), 예상액은 히어로 안에서만 표기.

## 8. 다크

- 히어로 A 배경 #1D4ED8, CTA 흰 배경 유지(대비 확보)
- 히어로 B 배경 #1B2536 + 보더 #2E3A4E, 숫자 #E6EDF7, 금액 #FBBF24
- 목록 행 #1B2536/#2E3A4E, 월 요약 바 #2E3A4E
- 경고 카드 배경 #3A2413, 글자 #FDBA74

## 9. 검증 항목

1. 근무 중 / 출근 전 / 근무 완료 / 일정 없음 4가지 상태가 각각 올바른 히어로를 낸다
2. 게이지 채움이 실제 경과/예정 비율과 일치하고 초과 시 clamp된다
3. 헤더 칩 금액 == 히어로 "지금까지" 금액
4. 남은 일 0건일 때 섹션이 사라진다(빈 카드 남지 않음)
5. 375px 폭에서 금액·CTA 줄바꿈 없음 (`flex:none; white-space:nowrap`)
6. 글자 크기 "아주 크게"(1.35)에서 히어로 카드가 깨지지 않음
7. 다크에서 4가지 상태 모두 대비 확인
8. 제거한 빠른실행 기능들이 각 화면에서 모두 도달 가능
