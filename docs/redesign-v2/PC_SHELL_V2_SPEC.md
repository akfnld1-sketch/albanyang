# PC 셸 명세 (PC SHELL v2) — 상단 탭 → 좌측 사이드바

레퍼런스: `머니냥 홈 강화안.dc.html` 의 **6c**, `머니냥 나머지 4화면 강화안.dc.html` 의 **8a~8d**
전제: 계산 로직 무접촉. `showPage()` 호출부·렌더 함수 무수정.

## 왜 지금 안 바뀌었나

2단계에서 "모바일 셸 먼저, PC는 기존 상단 탭 당분간 유지"로 합의했기 때문이다.
따라서 PC(>768px)는 여전히 이모지 상단 탭 + 빠른실행이 남아 있다. 이번 작업으로 정리한다.

## 1. 제거 — PC 상단 탭 전체

현재: `🏠 오늘 / 📋 정보 / 📅 근태관리 / 💰 수입관리 / 🛡️ 생존관리 / 📊 연간요약 /
🔧 직업 설정 변경 / ⚙️ 설정 / 📦 백업 / 📂 복원 / 🗑️ 초기화 / ❓ 도움말`

이 12개를 상단에서 전부 없앤다. 이동 위치:
- 6개 화면(홈·정보·근태·수입·생존·연간) → **사이드바 메뉴**
- 설정 → **사이드바 최하단**
- 직업 설정 변경 / 백업 / 복원 / 초기화 / 도움말 → **설정 화면 안**
  (설정 화면에 아직 항목이 없으면 이번에 추가한다. 기능 삭제 아님)
- 좌상단 햄버거(☰) + 달력 아이콘 → 사이드바가 상시 노출이므로 제거

## 2. 셸 레이아웃

```
body(>768px): display:flex; min-height:100vh; background:#EEF2F8
├ 사이드바  width:236px; flex:none
└ 본문      flex:1; min-width:0; display:flex; flex-direction:column
   ├ 상단 바 (고정 높이, 화면 제목 + 우측 액션)
   └ 콘텐츠  padding:24px 28px
```

모바일 스와이프 트랙은 PC에서 쓰지 않는다. PC는 사이드바 클릭 전환만.
`showPage()` 는 PC에서 기존 display 토글 방식으로 동작하게 분기한다.

## 3. 사이드바

```
배경 #1E3A8A (다크 #16233A), padding 20px 16px, flex-column, gap 20px

├ 로고: 냥이 아바타 32px + "머니냥" 17px/900 #F8FAFC, letter-spacing -.02em
├ 메뉴 6개 (gap 3px):
│   각 항목 = display:flex; align-items:center; gap:12px;
│            padding:11px 14px; border-radius:14px; font-size:15px
│   비활성: color #A9BCE8, weight 700, SVG stroke #A9BCE8
│   활성:   background #F8FAFC, color #1E3A8A, weight 900, SVG stroke #1E3A8A
│   순서: 홈 · 정보 · 근태 · 수입 · 생존 · 연간
│   정보 항목에만 읽지 않은 소식이 있을 때 우측 끝 빨간 점 7px (#DC2626)
│     → margin-left:auto 로 밀어 붙이고, 정보 화면 진입 시 제거
└ margin-top:auto 그룹 (gap 3px):
    ├ 월 예상 수입 박스: background rgba(248,250,252,.1), radius 14, padding 13/14
    │   라벨 12.5px #A9BCE8 + 금액 17px/900 #F8FAFC
    │   어느 화면에 있어도 보인다 — PC에서 사이드바를 두는 실질 이득
    └ 설정 항목 (메뉴와 같은 스타일, 톱니 SVG 19px)
```

**아이콘은 인라인 SVG 19px / stroke-width 2 / stroke-linecap round.** 이모지 금지.
6c·8a~8d의 path 값을 그대로 가져다 쓴다(홈=집, 정보=원+i, 근태=달력, 수입=원+₩,
생존=방패, 연간=막대, 설정=톱니).

## 4. 상단 바

```
padding:16px 28px; background:#F8FAFC(다크 #1B2536); border-bottom:1px solid #E2E8F0
좌: 화면 제목 22px/900 letter-spacing -.02em
    + 부제 13.5px #64748B (예: "2026년 7월", "7월 예산 · 월급날 8월 10일")
우 (margin-left:auto, gap 12px):
    ├ 화면별 컨텍스트 요소 (선택)
    │   홈    → 오늘 수입 칩 #FEF3C7/#B45309, 14px/900, radius 999, padding 7/13
    │   근태  → 미기록 칩 #FFEDD5/#9A3412
    │   수입  → "명세서 입력" 버튼 (#fff, 보더 #CBD5E1, radius 12)
    │   생존  → "지출 기록" 버튼 (#2563EB 채움)
    │   연간  → "연말정산 자료" 버튼
    ├ 마이크 44×44 원형 #F59E0B, shadow 0 4px 14px rgba(245,158,11,.32)
    │   ★ 모든 화면에 존재한다 (셸 chrome). 화면별로 빼지 말 것
    └ "냥이 비서" pill: #2563EB, radius 999, padding 7px 15px 7px 8px,
        냥이 아바타 28px + 텍스트 14.5px/900 #F8FAFC
        ★ 색은 항상 #2563EB. #1E293B(월 요약 바 토큰)를 쓰지 말 것
```

기존 플로팅 어시스턴트 아바타·상시 음성 바는 PC에서도 숨기고 이 두 요소로 대체한다.

## 5. 콘텐츠 — 좌측 결론 / 우측 근거

**PC에서 히어로를 키우는 게 아니라 위계를 넓힌다.** 결론은 하나이고, 넓어진 공간은
모바일에서 스크롤·팝업으로 숨겨야 했던 것을 미리 보여주는 데만 쓴다.
홈에만 있는 새 기능을 우측 열에 만들지 말 것.

| 화면 | grid-template-columns | 좌 | 우 |
|---|---|---|---|
| 홈 | `1.35fr 1fr` | 히어로 카드 (숫자 58px, CTA 56px) | 오늘 남은 일 · 날씨 · 경고 |
| 근태 | `1fr 1.25fr` | 기록 완성도 + 미기록 목록 | **전체 달력 상주** (팝업 아님) |
| 수입 | `1fr 1.15fr` | 실수령액 54px + 요약 3칸 | 구성 근거 막대 · 사업장별 |
| 생존 | `1fr 1.15fr` | "18일" 64px + 게이지 | 카테고리 4행 전개 |
| 연간 | `1fr 1.6fr` (상단) | 누적 수입 + KPI 4칸 | 월별 12개월 겹친 막대 |

- gap 20px, `align-items:start`
- 카드 radius 20 (모바일 16보다 크다), padding 20~26px
- **근태**: 모바일에서 팝업이던 전체 달력을 우측에 상주시킨다. 미기록 날짜는
  달력 셀에도 주황 테두리(#F97316 1.5px + 배경 #FFF7ED)를 줘서 좌우 열이 서로를 가리키게.
- **연간**: 모바일에선 9개월만 보였다. PC는 12개월 전부 + 작년 막대 겹침
  (올해 15px / 작년 10px, gap 3px)

## 6. 홈 — 빠른실행·자산카드 제거 (PC도 동일)

`HOME_V2_SPEC.md` §1이 PC에도 적용된다. 현재 PC 홈에 남아 있는
**빠른 실행 4버튼(출근하기·퇴근하기·지출 입력·급여 확인)** 과 내 자산 카드를 제거한다.

- 출근/퇴근 → 히어로 CTA 하나로 이미 대체됨
- 지출 입력 → 생존 화면 상단 바 "지출 기록" 버튼 + 마이크
- 급여 확인 → 사이드바 "수입" + 월 예상 수입 박스

제거 전에 각 경로가 실제로 존재하는지 확인하고, 없으면 먼저 만든 뒤 뺀다.

## 7. 반응형 경계

```
>= 1200px : 사이드바 236px + 2열 콘텐츠 (위 표대로)
1024~1199 : 사이드바 236px + 2열 유지, 카드 padding 20px로 축소
769~1023  : 사이드바 236px + 콘텐츠 1열 (우측 열이 아래로)
<= 768px  : 모바일 셸 (기존 스와이프 셸 그대로)
```

`min-width:0` 을 본문 컨테이너와 각 그리드 셀에 넣어 긴 금액이 열을 밀지 않게 한다.

## 9. 검증 항목

1. 6개 메뉴 + 설정 클릭 전환이 모두 동작하고, 활성 항목 스타일이 정확히 하나
2. 상단 탭 12개가 전부 사라졌고, 옮긴 5개 기능(직업 설정·백업·복원·초기화·도움말)이
   설정 화면에서 모두 도달 가능
3. **마이크가 6개 화면 전부에 있다** (화면별 누락 없음)
4. 냥이 비서 pill 배경이 모든 화면에서 #2563EB
5. 사이드바 월 예상 수입이 어느 화면에서도 보인다
6. 근태 우측 달력이 상주하고, 미기록 날짜가 좌우 열에서 같은 날짜를 가리킨다
7. 1023px / 768px 경계에서 레이아웃이 깨지지 않고 모바일 셸로 정확히 전환
8. 홈에서 빠른실행·자산카드가 사라졌고 대체 경로가 모두 살아 있다
9. 다크에서 사이드바 활성 항목 대비 확인
10. 브라우저 창을 좁혔다 넓혔을 때 리로드 없이 전환 (2단계 회전 결정과 동일 원칙)
