🧪 AI MVP 가상검증 시스템

배포된 MVP URL을 입력하면 가상 사용자 페르소나가 화면 구조를 기반으로 사용 경험을 검증합니다

STEP 1 · MVP URL 입력

🔗 MVP URL 입력

MVP 주소만 입력하면 공개 화면(HTML)을 자동으로 수집해 분석합니다. 별도 설정이 필요 없습니다. (로그인이 필요한 화면이나 봇 차단 사이트 등 자동 수집이 안 되는 경우에만 고급 설정의 수동 방법을 안내합니다.)

⚙️ 고급 설정 · 자동 수집이 안 될 때

수동 방법 1 · 페이지 소스 붙여넣기

MVP 페이지에서 우클릭 → "페이지 소스 보기" → 전체 복사 → 아래에 붙여넣기. (React/Vue 등 SPA는 DevTools에서 렌더링된 HTML을 복사하면 더 정확합니다)

수동 방법 2 · 저장한 HTML 파일 업로드 (여러 페이지 가능)

브라우저에서 Ctrl+S로 "웹페이지(HTML만)" 저장 후 업로드. 로그인 뒤 화면도 로그인 상태에서 저장하면 분석할 수 있습니다.

참고 · 화면 미리보기 (표시 전용)

보안 정책상 미리보기 화면 내부를 시스템이 읽거나 조작할 수는 없습니다. 눈으로 확인하는 용도입니다. (사이트가 iframe을 차단하면 표시되지 않습니다)

위 화면은 참고용 미리보기입니다 — 검증 엔진은 확보된 HTML 구조만 분석합니다.

🛠️ 개발자 설정 · 프록시 (일반 사용자는 건드릴 필요 없음)

자동 수집용 프록시는 앱에 기본 내장되어 있어 일반 사용자는 설정이 필요 없습니다. 아래는 개발자가 기본 프록시를 임시로 다른 주소로 덮어쓸 때만 사용합니다. (배포 방법: 프로젝트의 proxy/README.md)

ℹ️ 이 시스템은 실제 브라우저 자동 조작(버튼 클릭·페이지 이동)을 수행하지 않습니다. 확보된 화면 구조를 기반으로 한 사용 시뮬레이션이며, 결과에도 그렇게 표시됩니다.

📋 MVP 정보 확인·보완

화면 구조에서 자동 추출된 값이 미리 채워집니다(확보 시). 모든 항목은 선택 입력이며, 입력이 적을수록 검증 신뢰도가 낮아집니다.
